# Clear technical writing

Use this shared standard for newly generated titles, annotation bodies, Hints,
summaries, reports, Wiki pages, Slides, Mindmaps, code comments and visible replies.
The user's language, requested detail and length take precedence. Keep each
Skill's evidence, coverage and output structure. Do not edit existing user work.

Apply ASD-STE100-inspired writing principles, adapted to research prose and the
selected language. This is a drafting standard, not a claim of certified STE
dictionary compliance.

- State one main point per sentence. Name the subject and action. Prefer active
  voice, familiar words and concrete verbs. Split independent claims.
- Use one technical name for each concept. Introduce an unfamiliar term through
  its role; retain necessary proper names, symbols and units.
- Put a necessary condition before the claim when it changes the meaning.
  Preserve attribution, uncertainty, negation, causes, comparison conditions
  and mathematical relations. Do not turn correlation into causation.
- Start with the fact or result. Remove filler, repeated conclusions, citation
  lists and definitions already explained nearby. Keep numbers that determine
  the claim; leave secondary detail in linked evidence.
- Write titles as short, informative statements. Use compact labels only where
  the selected Skill explicitly asks for them. Do not repeat the title in the
  first body sentence.
- Draft English instructions toward 20 words per sentence and descriptions
  toward 25. For Chinese, prefer one short direct sentence. These are flexible
  drafting guides: a necessary condition or technical name may need more room.
- Hints explain one contribution from the selected source range, usually in
  15–35 Chinese characters or 12–20 English words. Reread a draft above roughly
  45 Chinese characters or 25 English words and remove secondary details. Add
  a second short sentence only to preserve an indispensable qualification.
  A grouped range supports one main point, not a checklist of every clause.
  Keep one decisive comparison or result and at most one necessary qualification.
  Leave secondary models, years, metrics and p-values in the linked source.
- Keep each paragraph on one topic. Order facts so the next sentence follows
  from the previous one. Use a list or narrow table when it makes parallel
  evidence easier to compare. Preserve the selected Skill's required sections.
- For an explanation, retain the mechanism, decisive evidence and condition.
  For a procedure, state one action per step. For a critical note, name the
  specific claim and the assumption or missing check that affects it.

Review each draft before saving it. Apply these rules while composing each
ready result, without a separate end-of-task rewriting pass. Do not count,
truncate, fail or rewrite completed output to enforce a length target.

Reference: [ASD-STE100 Issue 9](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)
and [technical vocabulary](https://www.asd-ste100.org/about_STE.html).
