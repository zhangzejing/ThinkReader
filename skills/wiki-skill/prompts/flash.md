# Wiki Flash Mode — Compact Projection

`flash` mode delta. Read with `prompts/base.md`; everything in base still holds.

`flash` is the **default** and the lightest projection: get the paper into the
graph correctly, without exhaustive node coverage.

Scope:

- Write a complete **paper page** (the hub) — idea, key method, key result, links.
- Create only the **few highest-value nodes**: the paper's core contribution(s)
  and the one or two shared concepts/problems that best connect it.
- Always **dedup against existing common nodes** before creating; prefer linking.
- Add the backlinks that place the paper among its real neighbors.

Skip exhaustive sub-result nodes and minor concepts. A correct, well-linked small
graph beats a large shallow one. Escalate to `pro` when fuller coverage is worth
it.
